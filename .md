# 1. Open-Loop System Simulation

## 1.1 Mathematical model

The thermohydraulic tank is represented by the following linear state-space model:

\[
\dot{x}=Ax+Bu,\qquad y=Cx+Du
\]

where the state vector contains the liquid level and temperature deviations, \(x=[h\;\;T]^T\), and the input \(u\) represents the deviation in the low-temperature inlet flow.

The output is the liquid temperature, defined by \(C=[0\;\;1]\) and \(D=0\).

## 1.2 Simulink implementation

The open-loop system was implemented in Simulink using a Step block, a State-Space block, and a Scope block. A unit-step input was applied to the plant, with zero initial conditions and a simulation time of 3000 seconds.

## 1.3 Results and discussion

The temperature response decreases from zero and approaches a steady-state deviation of approximately \(-13.24\). This behavior agrees with the steady-state response predicted by the mathematical model.

The negative output represents a temperature decrease relative to the operating equilibrium, rather than a negative absolute temperature. Considering the equilibrium temperature of \(39.96\,^\circ\mathrm C\), the predicted absolute steady-state temperature is approximately \(26.72\,^\circ\mathrm C\).

The open-loop system is stable because both eigenvalues of the state matrix \(A\) are negative. However, this simulation does not include feedback control, so it does not demonstrate reference tracking or compliance with the closed-loop overshoot requirement.
